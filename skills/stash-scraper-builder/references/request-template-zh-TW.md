# 刮削器需求表（正體中文）

**用途：** 請人或 AI 建立 Stash 刮削器時使用。會填的填，不會的留空。

> **概要：** 一頁式需求表。填好範圍、URL、欄位、清理規則、模式、測試案例，減少猜測與返工。

## 1. 需求表（會填的填）

| 欄位 | 你的填寫 | 說明 / 範例 |
| --- | --- | --- |
| **範圍** |  | `scene`（影片）, `performer`（演出者）, `movie/group`（系列）, `gallery`（寫真）, `image`（單圖） |
| **想要的模式** |  | `sceneByURL`, `sceneByFragment`, `sceneByName`, `performerByURL` 等 |
| **網域** |  | 例如 `site.test` |
| **影片 URL 範例** |  | 例如 `https://site.test/works/ABP-123` |
| **演出者 URL 範例** |  | 例如 `https://site.test/actor/Alice` |
| **搜尋 URL** |  | 例如 `https://site.test/search?q={}` 或「無搜尋」 |
| **存取方式** |  | 公開 / 需登入 / 付費牆 / 純 JS 渲染 |
| **Action 類型** |  | `scrapeXPath`（HTML） / `scrapeJson`（JSON API） / `script`（Python） |
| **影片欄位** |  | 標題、日期、簡介、封面、演出者、製作商、標籤… |
| **演出者欄位** |  | 姓名、性別、生日、身高、照片、社群帳號… |
| **標題清理** |  | 例如「去掉尾端 `[...]`、`【...】`、副檔名，折疊空白」 |
| **日期範例** |  | 例如 `2024.03.15`, `15 Jan 2024`, `2024年1月15日` |
| **演出者姓名規則** |  | 例如「漢字 > 英文 > 假名」（若適用） |
| **特殊狀況** |  | 例如「日期有 `&nbsp;`」、「標題有 `[4K]」」、「製作商是網域」 |
| **限制條件** |  | 例如「不用 CDP」、「必須用 visible-CDP」、「若無真實搜尋就不要 `sceneByName`」 |

## 4. 送出前檢查表（手動）

送出前請勾選：

- [ ] 範圍與實體類型清楚（影片 / 演出者 / …）。
- [ ] 想要的模式已列出，且網站真的支援。
- [ ] 每個模式至少有一個真實 URL。
- [ ] 若用 `scrapeJson`，已附上 JSON 範例。
- [ ] 標題、日期、演出者清理規則有例子。
- [ ] 存取方式已說明（公開 / 登入 / 付費牆 / JS-only）。
- [ ] 任何限制（不用 CDP、不要搜尋等）已寫明。
- [ ] 若需登入/付費：你接受 visible-CDP 步驟，或接受「超出範圍」。
